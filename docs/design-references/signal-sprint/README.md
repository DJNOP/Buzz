# Signal Sprint design-direction references

These two images are user-approved visual direction references. They are not
runtime assets, generated build inputs, or literal pixel-perfect implementation
requirements.

## Lighting golden frame

`lighting-golden-frame-reference.png` controls the provisional Lighting
interaction standard: a readable robot physically operating a layered console,
foreground overlap, a dynamic target monitor, one dominant primary control,
four grouped secondary controls, stable character anchors, and a visible
robot-to-station-to-stage consequence chain. Small props, background details,
microcopy, and exact illustrated complexity are non-binding.

## Four-player composition

`four-player-composition-reference.png` controls shared-venue composition,
relative workstation scale, television-distance hierarchy, one common timer,
compact identity/progress, and a subordinate audience/background. The
Decorations station shown in this reference is not approved final art.

The current milestone upgrades Lighting only. Sound, Decorations/event setup,
and Machinery retain their existing presentation until the Lighting interaction
standard has been tested with real players and a physical television.
